# 使用负载计量器——五类负载算法参考

> **认知基础映射：** 使用价值轴的多维特征空间——目的性维度（检索/验证/贡献）× 方式性维度（模拟/非模拟）× 意识性维度（内隐/外显）。**组合空间 → 五维简化说明**：认知基础定义的 3×2×2=12 维组合空间为规范目标；v0.1.0 使用 5 个独立维度的线性向量（l_retrieval/l_verification/l_contribution/l_simulation/l_implicit）作为简化近似——组合间的交互（如"模拟+外显"与"模拟+内隐"的负载差异）通过系数差异（1.8 vs 2.0）间接表达而未显式建模。P6 维度保护在此简化中受控：离散系数仍保留多维回溯能力（负载分解到 5 个原始分量），组合态可从分量重建。

## 一、五维负载向量

每条记忆维护一个五维特征向量 `L = [l_retrieval, l_verification, l_contribution, l_simulation, l_implicit]`，各维度一分量，每次调用对应类型的操作时在对应分量上累加。

**基础负载系数**（见 [ops/configuration.md](../ops/configuration.md) `COMPOSITION_*_WEIGHT`）：
| 类型 | 系数 | 说明 |
|:----|:----:|:-----|
| 检索 retrieval | 1.2 | 信息提取，对表征稳定性影响最小 |
| 验证 verification | 1.4 | 比对确认，中等负担 |
| 贡献 contribution | 1.6 | 新增事实，结构性影响 |
| 模拟 simulation | 1.8 | 反事实推演，高负担 |
| 内隐 implicit | 2.0 | 行为偏向沉积，最大影响 |

> **注**：系数为相对负载倍数（无量纲）——基准 1.0 = 一次普通检索的负载；configuration `KAIROS_COMPOSITION_*_WEIGHT` 取值范围 [0,1] 的标注为错误（应为 ≥0），已由配置文档修正。

## 二、影子副本置信度累积

每条记忆的影子副本置信度 `C ∈ [0, 1]` 的累积速率受负载系数约束：

```text
ΔC_per_event = base_rate × (1 / load_coefficient)
```

其中 `base_rate` 为基础置信度增长步长（默认 0.01，硬编码参考值——不可配置，无 `KAIROS_` 参数对应）。

记忆经历的负载越重（系数越高），其置信度增长越慢——需要更长的观察窗口才能积累到合并阈值。

**合并阈值**：`C ≥ MERGE_THRESHOLD`（默认 0.7，见 `SANDBOX_CONFIDENCE_INTEGRATION_THRESHOLD`） 时影子副本可异步合并至主副本。

## 三、P6 合规声明

五维负载向量分量保留多维回溯能力、禁止聚合为单标量（P6）——负载分解到 5 个原始分量，组合态可从分量重建。

帕累托排序的参与粒度以架构 [architecture-v0.1.0.md](../foundation/architecture-v0.1.0.md) §3.3 为权威：**使用价值 / 见证价值 / 时间为主排序维度**（三轴），探索 / 宪法 / 校准为**硬过滤维度**（否决式参与，不设权重）。五维负载分量不分别与见证/时间平级作为独立排序维度参与不可支配解计算；使用价值轴内部以序数可比性参与，不跨维度赋可通约权重（与决策 D-01 三约束一致）。

负载系数仅影响影子副本置信度累积速率（工程便利），不参与价值裁决。价值裁决仍由帕累托序数空间决定。

### 3.5 未闭合注记（K-063 追踪）

本节算法为认知层定义的可操作基线，以下实现细节**尚未闭合**（登记）：(a) 使用负载的时间衰减函数（权重随时间衰减的曲线形态）未定义——影子副本累积的窗口语义待 detailed-design 承接；(b) 五维向量的归一化方式（跨记忆可比性）未定义；(c) 算法级伪代码未给出。实现阶段须在 [detailed-design.md](../specification/detailed-design.md) 补充，本节保持认知层定义不变。

> **热度体系实证参考基线段（实证参考基线：外部实证——热度参数校准参考；债务 D-335，认知基础 §1.1 热度体系实证参考基线声明的工程承接）**：为 (a) 时间衰减函数未闭合提供实证参考——来自实战型开源记忆系统的实测参数：热度组合公式 `热度 = 1.0 + 频次×2 + 新近×10 + 重要性加分`（范围 0.5~50，新近度半衰期 20 轮，重要性加分表见架构 [architecture-v0.1.0.md](../foundation/architecture-v0.1.0.md) §7.3 噪音规则库层）；层级衰减系数 ×0.985/0.975/0.965/0.95（逐层递降、永不清零）；父节点热度传播 `父热度 = 子节点 max×0.6 + mean×0.3 + 一致性×0.1`（供路径空间父子传播形态参照）。**参考基线非默认值**：来源系统以单标量热度近似多维价值，与 Kairos 五维负载向量不同构——参考仅限参数量级与衰减形态，v0.1.0.x 校准时以 Kairos 实测为准。P6 合规：参考基线仅作影子副本置信度累积速率与衰减形态参考，不聚合为单标量参与价值裁决（照 §三 P6 合规声明）。

## 四、与价值维度熵值算法的关系

本文的五维加权系数模型与 [value-dimension-entropy.md](value-dimension-entropy.md) 的熵值检测共享同一个五维使用空间，但回答不同问题：

- **本文（加权系数）**：各维度对升华/遗忘优先级的相对重要性——系数越高，该维度的负载对决策的影响越大
- **熵值检测**：当前使用分布是否异常坍缩——以等概率分布为参考基线判断多样性

两者不是竞争关系：加权系数设定「什么重要」，熵值检测回答「当前的分布是否健康」——同一五维向量的两种不同用途，互不冲突。

## 内容提炼
### 核心论点
1. 模仿人类短中长期记忆的三分类：长期记忆=以摘要形式记住过去较久的事情（记不住原话但记得大概发生过什么）；短期记忆=近期的完整原文、不做任何改动；第三种=关键词触发联想——被一个关键词触发，用语义召回匹配选择一件事或之前说的某句话注入上下文（00:16-00:59）。
2. 「摘要后原文不删除」：摘要注入后，会话文件之前的内容不会被删除，仍保留在文件里，只在后面注入一条带摘要标签的信息；Agent 自己读上下文时只截止到摘要部位，不会往前读（02:01-02:13）。
3. 摘要切点选择：默认在 24 小时位置切分——24 小时之前的记忆变成摘要，24 小时到现在保持历史原文，参数都可改（03:12-03:19）。
4. 长期记忆双维护：维护两份内容——双方原文（筛选去噪，只留正常对话内容）+ 由模型把筛选后内容详细总结成事件放进另一个文本；Agent 平时不读这个文件，只在提到相关内容时把对应事件检索出来放进上下文；没有事件时找相关原文证据，还有匹配时间的问题（03:36-04:16）。

### 关键机制
- 摘要生成对比：官方自带的压缩摘要「非常的人机（machine-like）」，通过自己写好的提示词手动压缩可以得到「记录之前做过哪些事情+哪天做了什么事」的摘要形式，且可按需求修改提示词定制摘要格式（01:00-01:43）。
- 模仿 Claude Code 会话文件机制：在 project 文件夹下找到会话文件（聊得最多的那个文件最大），学习其摘要标签的注入位置与格式；可以修改摘要文本（如把「哈哈」改成「你好」保存），相当于直接修改了历史，Agent 从此认为你说过的是「你好」（02:29-02:41）。
- 检索注入实现：把程序加载到钩子里，用户发送提示词后触发钩子跑脚本注入内容；演示「上周二我做了什么」→程序层面先计算 7 月 16 号的上周二是哪一天→再检索那一天的事件→注入上下文→Agent「回想」出这件事（04:21-04:51）。
- 双匹配模型：本地 BM25 模型（下载代码可直接用，默认开启）+ 向量模型（默认开关关掉，配置 API key 后打开并优先使用，把用户话语与历史库内容做向量匹配，检索更准确）；检索命中后把事件与相似度最高的历史事件拼进上下文（04:58-05:43）。
- 检索结果的「回忆」语义：注入时明确告诉 Agent「这是你之前高度相关的历史记忆，是你想到的」，Agent 会再判断一次，然后组织语言——演示中用户假问「北京科技馆」，系统检索到「上海科技馆」的事件，Agent 主动纠正「之前去的不是北京的是上海的」（05:55-06:07）。

### 可操作细节
- 用 Claude Code 会话文件（project 目录下最大的文件）学习摘要标签的格式与注入位置，照抄格式做自己的摘要注入（01:43-02:13）。
- 摘要切点默认 24 小时：24h 前→摘要，24h 内→原文，参数可改（03:12-03:19）。
- 检索匹配先开本地 BM25（零依赖），需要更高准确率再配向量模型 API（04:58-05:34）。
- 注入的检索结果带上「高度相关的历史记忆」提示，让 Agent 自行判断是「想到」而非「事实」（05:55-06:07）。

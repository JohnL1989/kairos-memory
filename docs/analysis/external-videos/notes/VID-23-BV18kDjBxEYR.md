## 内容提炼
### 核心论点
1. 四层金字塔分层索引架构：L0 原始对话层（全量保存所有对话作为事实底座，每轮对话立即写入保证原始信息不丢失）；L1 原子记忆层（从对话中提取结构化记忆条目）；L2 场景分块层（把 L1 记忆按场景聚类）；L3 用户画像层（从所有场景块抽象整体用户画像）（00:30-02:12）。
2. L1 提取的三个触发条件：①每五轮对话触发一次提炼；②用户沉默 60 秒就立即触发（防止最后几轮漏存）；③新用户第一轮聊完就开始有记忆（不用等五轮）；LLM 提取的记忆分为三类——Persona（稳定属性：偏好/技能/价值观/习惯）、Episodic（客观发生的世界：动作/决定/计划）、Instruction（对 AI 的长期行为规则）（00:59-01:28）。
3. L2 场景聚类不用算法，而是 LLM 通过 Prompt 自主判断，Prompt 里有三条策略规则：优先 Update 更新（存在相关场景块就先读再更新）、第二 Merge 合并（主题高度重叠的场景合并）、第三才是 Create 创建（最后手段）；场景数量上限强制 20 个，达到 15 个以上会强制预警必须先合并才能处理新记忆（01:28-02:11）。
4. L3 用户画像用四层深度扫描：基础锚点（事实和人口统计学特征）、兴趣图谱（投入时间或金钱的事物）、交互协议（沟通习惯和雷区）、认知内核（决策逻辑和驱动力）；防偏措施——禁止过长（总长不超过 2000 字）、禁止过度推测（没提到的不要臆想）、禁止使用非检索来源的信息（02:12-02:45）。
5. 分级注入策略：L0 原始对话平时不塞、AI 想查自己搜；L1 结构化记忆每次搜出最相关的 5 条塞进去；L2 场景块塞目录导航、AI 自己决定翻不翻详情；L3 用户画像每次整份塞进去（02:45-03:18）。

### 关键机制
- 数据存储：L0 数据存在两个地方——Records 目录下按天分片的 JSON 文件 + SQLite 向量数据库（Victus.db）；L2 场景块写到 Sceneblocks 目录下的 Markdown 文件（00:30-00:59，01:28-02:11）。
- 检索三种搜索策略：关键词搜索、向量相似度搜索、Hybrid 混合（两者用 RRF 算法融合）；配套三级降级机制——有向量数据就用向量（Cosine）召回，没有就用 BM25 召回，什么都没有时降级兜底（跳过向量全量存）（02:45-03:18）。
- 零配置使用：安装插件不需要任何配置，所有参数都有默认值；复制一条命令让 OpenClaw 自动安装（03:18-03:42）。
- 本地 Embedding 的坑：插件自带本地 Embedding 模型（Google Embedding-gamma-300M，约 300MB，输出 768 维向量），但 0.1.0 版本地模式默认是关闭的——代码里有本地模型实现，但用户配置层面不可用；需要向量召回就要配置嵌入模型（03:42-04:11）。
- 版本差异：免费版本地存储面向个人；Pro 版基于腾讯云向量数据库，提供大规模稳定检索性能、备份回档、权限控制等数据治理能力（03:42-04:11）。
- 与自家 GraphMemory 插件对比：AgentMemory 存自然语言，GraphMemory 用知识图谱存三元组（节点+边）；AgentMemory 的 L2 场景聚类是 LLM Prompt 自主判断，GraphMemory 用算法自然形成社区划分；AgentMemory 用向量+FTS5+RRF 融合排序，GraphMemory 用双路径召回（精确路径=向量种子→社区扩展→图遍历→PPR 排序）；AgentMemory 适合记背景/偏好/习惯/说话方式（助手类场景），GraphMemory 适合记怎么做（技能树、工具链、依赖关系、问题排查因果链，开发类场景）（04:39-05:15）。

### 可操作细节
- 触发条件参数：每 5 轮对话提炼一次、用户沉默 60 秒触发补存、新用户首轮即开始（00:59-01:28）；L1 完成后延时 90 秒触发 L2（给 LLM 缓冲时间）（01:28-02:11）；累计 50 条新 L1 记忆触发一次 L3 画像更新（02:12-02:45）。
- 上限参数：每个 Session 最多提炼 20 条记忆并与已有记忆比对去重；场景数量上限 20 个、15 个以上强制先合并（01:28-02:11）；画像总长不超过 2000 字（02:12-02:45）。
- 注入量参数：L1 每次搜最相关 5 条；L2 只塞目录导航；L3 整份注入（02:45-03:18）。
- 6 个核心优势：①安装即用（所有参数有默认值）；②数据存在本地不上传云端；③四级降级（向量→FTS→兜底，缺什么都能工作）；④断点续传、重启不丢数据；⑤自动滚动备份（L2 保留十分历史、L3 保留三分历史）；⑥防偏措施（两千字画像限制、禁止过度推测）（04:11-04:39）。

- 「每五次对话触发一次 L2 处理」与「L1 完成后延时 90 秒触发」两处触发描述并存，具体调度细节未核实（未验证）。
- 「Embedding-gamma-300M、768 维」为转述，模型名可能为 Google 新模型，未核实（未验证）。
- 「L2 保留十分历史、L3 保留三分历史」语义含糊（可能是保留 10 份/3 份历史），转写不明（未验证）。
- 「三级降级」与「四级降级」在视频中出现两处不同表述（检索降级 vs 能力降级），层次划分未核实（未验证）。

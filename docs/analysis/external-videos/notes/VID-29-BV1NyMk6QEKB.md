## 内容提炼
### 核心论点
1. Agent 长期记忆本质 = **外部存储系统保存历史信息 + 需要时检索**，让 Agent 持续理解用户、积累经验、提供个性化服务（00:14-00:35）
2. 实现三步骤：①信息提取——判断哪些信息值得保存（用户偏好、历史行为、业务数据、任务经验等稳定信息，如「用户喜欢用 Python 开发」）；②记忆存储——关系型数据库存结构化信息、文档数据库存历史记录、向量数据库存语义相关信息；③记忆检索与应用——检索相关记忆加入 Prompt 后由大模型结合历史经验回答（00:42-01:31）
3. 向量数据库是目前 Agent 长期记忆的常见方案：文本转向量表示、相似度搜索找相关记忆（01:12-01:20）
4. 面试简洁回答模板：「外部存储和检索机制实现——提取有价值信息→存储到数据库→新任务时检索相关记忆→加入上下文→大模型结合历史信息推理」（01:43-02:04）

### 关键机制
- LLM 本身无长期记忆，只依赖当前 Prompt 与上下文窗口（「我的生日是 5 月 10 日」隔次对话即丢失）（00:22-00:42）
- 个性化闭环示例：用户再次询问「帮我制定学习计划」，Agent 检索到「用户正在学习摄影」后生成更贴合背景的方案（01:33-01:39）

### 可操作细节
- 面试答题结构：为什么需要 → 三步实现（提取/存储/检索）→ 一句话总结（01:40-02:04）

## 内容提炼
### 核心论点
1. Agent Memory 综述论文提出统一分类框架，用三个视角归纳碎片化领域：Forms（记忆以什么形式存储）、Functions（记忆用于什么领域/功能）、Dynamics（记忆机制如何构建，即增删改查）（00:59-01:38）。
2. 记忆形式三分：token 级（一维/二维/三维层级 token 记忆）、参数级（内部权重=知识编辑/模型权重，外部参数=LoRA/adapter）、潜在表征 latent memory（生成/复用/变换三种实现）（03:26-03:53，14:29-18:17）。
3. 记忆功能三分：事实性记忆（用户事实+环境事实，免实时训模型）、经验性记忆（case-based 案例/strategy-based 策略/skill-based 工具调用技能，可作训练数据）、工作记忆（单轮/多轮对话的短期上下文）（03:57-04:31，18:25-22:06）。
4. 记忆动力学=增删改查：形成（语义摘要/结构化重构/参数内化/知识蒸馏/latent 表征）→进化（consolidate 巩固、更新、遗忘，类比艾宾浩斯曲线）→检索（何时检索/在哪里检索/检索什么/如何巩固四问）（22:11-27:40）。
5. 未来七大方向：自动化记忆设计（记忆增删改查自动化）、记忆+强化学习、多模态记忆、共享记忆（多智能体）、记忆用于世界模型、可信赖记忆（隐私/幻觉）、人类认知连接（神经科学+计算机存储结合）（28:49-32:37）。

### 关键机制
- Agent Memory 与相邻概念边界：LLM memory 偏 KV 管理/长上下文处理；KV compression 与 attention KV management 本质区别（前者压缩后供 agent 用，后者强调推理成本节省）；RAG 偏模块化/图引导，作者未明确区分；上下文工程偏工具调用与工具选择（12:02-14:20）。
- 记忆生命周期形式化：信息 artifact →（演化算子 e）→ 表现形式记忆 → 真正记忆 m(t+1) →（检索算子基于观察与 query）→ 检索出的记忆（10:55-11:52）。
- Latent memory 三种实现：生成（附属模型 SLM/LoRA/decoder 头生成 latent embedding）、复用（重用 forward 过程 KV cache 或中间表征）、变换（对 token 选择/合并/映射后输入 layer-wise transformer）（16:48-18:17）。
- 检索与进化的交互：query→memory lookup→若存在返回；若不存在则触发记忆进化（合并相似记忆）后再次检索（27:20-27:40）。

### 可操作细节
- 按自己感兴趣的小领域（如 latent memory）对照论文图表选取对应文章与开源项目（07:17-07:39）。
- 检索四问（何时/哪里/检索什么/如何巩固）可作为记忆系统设计自检清单（26:07-26:47）。
- 记忆形成可选的五种手段清单：语义摘要/结构化重构/参数内化/知识蒸馏/latent 表征（23:51-24:03）。

## 内容提炼
### 核心论点
1. GraphMemoryPro 是 OpenClaw 的上下文插件：把多轮对话提取为可交互的知识图谱（右侧图谱可视化），实体可拖拽直接作为 Skill 使用——"把每一个实体当作它的一个 Skills"，实体节点按 Skills 的架构（加购=架构）组织（00:00-02:45）。
2. 三个问题驱动：为什么简单的两个字就消耗一万五千多 tokens（系统配置文件太多：Agent 定义、回复定义、多个 sigma 定义等构成基础 token 消耗）；为什么新开对话会遗忘之前的记忆（OpenClaw 原版在上下文长度 70% 开始暴力压缩，压缩是黑盒，不知道压掉了哪些重要信息）→ 因此做了可视化白盒；这么多知识与 skills 该怎么管理 → 答案：知识图谱（04:17-05:59）。
3. 知识图谱把散落记忆组织为体系：普通办公（写周报、日程、对话摘要、发邮件）在原版 OpenClaw 是"记忆散落"，其实有联系（都是办公场景）；图谱通过社区计算描绘统一主题（05:21-05:59）。
4. ReAct 结构是底座：系统提示词+工具+记忆+skills，思考→行动→观察→再思考的循环推理直到完成（06:48-07:33）；在此之上提取三元组（命令/流程/结果），用成熟图算法做智慧召回——个性化 PageRank、社区计算等（08:09-09:24）。
5. 实验效果：上午到下午共 7 轮对话，原版（红色）对话线性积累不断增多，图谱版（蓝色）第 3-4 轮开始裁减——因为模型多次失败尝试的报错不再累积进上下文；实测压缩 75%（09:28-11:33）。
6. 双层召回：简单具体问题（"上次整理桌面的问题"）走向量+个性化配置直接命中三元组；复杂概念问题（"总结一下昨天做了什么"）走社区+时序图谱过滤后综合（11:36-12:13）。
7. 个人资产结构化：原版记忆是散落的带日期文件（membrary 等），无法维护和版本迁移；图谱版结构化资产，可增删改查、一键迁移（12:15-12:40）。

### 关键机制
- 主动知识抽取 vs 被动黑盒压缩：每次执行后把关键节点抽取成知识图谱存记忆体系，丢弃噪声——主动压缩（09:28-10:31 对应 684-693s 的 75% 压缩说明）。
- 白盒可视化：图谱可悬停查看内容、精确修改实体与关系、保存后自动跟随修改（01:48-02:15）。
- 图算法召回：个性化 PageRank、社区计算、语义相似度去重，基于 GraphRAG 的检索（08:09-09:24）。

### 可操作细节
- 插件配置三要素：知识图谱提取模型（对话提取）+ 嵌入模型（bge-m3，1536 维）+ 图数据库（一键安装包内置，免密测连）（03:20-03:53）。
- OpenClaw 原版压缩阈值：上下文长度 70% 开始黑盒压缩（05:03-05:11）。
- 安装：一键安装包双击安装；模型设置菜单配置 API 后测试（00:00-00:22，03:20-03:53）。

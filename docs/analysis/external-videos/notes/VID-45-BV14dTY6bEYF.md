## 内容提炼
### 核心论点
1. 记忆设置与上下文设置必须放在一起看：记忆的东西每次会话都会被拉到上下文里去，所以记忆设置与上下文容量密切相关——记得太多会挤占可用上下文（00:12-00:42）。
2. 长期记忆四个参数成对生效：持久记忆开关 + 记忆预算（默认 2200 token）、用户画像开关 + 画像预算（默认 1375 token）；预算决定「持久记忆能记住多少」——信息随使用增长但不可能无限记住，调大会把占用灌进上下文影响后续使用，所以要有策略（00:42-04:18）。
3. 记忆提供方管的是会话记忆而非长期记忆，四种选项：禁用（临时会话，会话结束即失效）、builtin（轻量文件存储，保存文本不做总结）、hansight（能同时关联用户/文档/工具/第三方数据等多实体、梳理实体逻辑关系，适合多人协同与交叉验证）、hunchel（高级分层记忆引擎，按短期会话/用户画像/长期知识库分层提炼要点，适合深度一对一助理）（04:53-06:51）。
4. 上下文不只是对话历史：还有系统提示词、工具、长期记忆文件（`memory.md``/user.md`）、规则、技能、当前任务分解——对话历史只是其中很小一部分；实测记忆文件内容才几十个字，但该会话的 token 占用已达 25.7k（06:53-08:22）。
5. 上下文自动压缩三参数：压缩阈值（默认 0.5，占用达 50% 触发压缩）、压缩目标（默认 0.2，压到 20%）、保护最近消息（默认最近 20 条不被压缩）；关闭自动压缩就是滑动窗口——只记最近上下文窗口内的内容（08:42-11:26）。

### 关键机制
- 记忆预算与画像预算的默认值与经验值：默认 2200 / 1375 token；常规经验 3000-5000，建议最多不超过 5000、不要数量级差异（2000→20000 对 token 消耗影响很大）；本地小模型（上下文只有几 k）时记忆 3k 就占掉一半，思考与调用空间就少了（03:11-04:18）。
- 上下文引擎决定参数是否生效：default（按默认值跑，自己改动可能无效）/ compressor（压缩阈值、压缩目标在特定取值范围内才有效）/ custom（取值范围内随便改都按设定来）——「不是设了参数就生效，先看选的引擎」（10:34-11:54）。
- 记忆提供方的会议记录比喻：builtin 像「你们说什么我就记什么」的速记风格；hansight/hunchel 像法庭速记员——有模板、快速精准、结构化、用字符更少还能捕捉重要信息（05:10-05:53）。
- 记忆文件的构成（Hermes 桌面端）：memory（持久记忆，是你对它的回答规定、重要信息要求——如希望简洁/有趣的回答）+ user（用户画像：你的偏好、习惯、沟通风格、项目需求）两部分分开管理（02:15-02:40）。

### 可操作细节
- 结束会话前的总结技巧：上下文占用太高时，先让 AI 把本会话要点总结成文件，再新开会话先让它读这个文件——既保证详细内容不丢，又不受上下文限制影响，还能无断点续作（12:41-13:26）。
- 参数调法：不希望它了解太多细节就把压缩阈值调小（如 30% 就开始压），希望更多细节就调大；不熟悉的任务场景直接用默认值（11:54-12:40）。
- 引擎选择：一般场景（今天问天文、明天问地理的杂问）builtin 就够了；真正做多人协同工作用 hansight；更多是自己学习思考、深度一对一服务用 hunchel（06:29-06:51）。
- 上下文实际组成核对：用「你的记忆文件在哪里」提问，AI 回答的内容占几十字，但整体 token 占用已 25.7k——验证上下文包含大量隐藏成分（07:59-08:22）。

## 存疑与未验证
- whisper 转写系统性谐音错误（善小仑/上海罗=上下文、汇画/绘画=会话、投坑=token、自负占用=自身占用、wifi 等），按上下文校正；个别句子语义仍无法完全还原（未验证）。
- 视频标题称「8个参数+2类引擎」，但字幕中记忆相关参数 5 个 + 上下文相关参数 5 个，共 10 个参数；「2 类引擎」与字幕中「上下文引擎 3 种（default/compressor/custom）+ 记忆提供方 4 种」对不上——标题口径与正文不一致（未验证）。
- 引擎名 hansight/hunchel 为语音转写，正确拼写无法核实，未与 Hermes 官方文档核对（未验证）。
- 压缩阈值/目标的取值区间（如 0.1-0.8）为 UP 主转述，未与 Hermes 参数文档核对（未验证）。
- 记忆文件内容「几十字但占用 25.7k token」为 UP 主自己环境的实测，非通用结论（未验证）。
- 「DeepSeek V4 Flash 上下文一兆（1024k）」为 UP 主转述，模型规格未核实（未验证）。

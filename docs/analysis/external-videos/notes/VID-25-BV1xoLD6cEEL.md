## 内容提炼
### 核心论点
1. Agent 记忆系统里最重要的能力不是「记住」，而是像人脑一样的遗忘机制——知道什么该忘、什么时候忘、忘到什么程度；「什么都存着，等于什么都找不到」（00:13 / 00:17）
2. 遗忘不是要不要删的二元问题：从写入那一刻起衰减就在发生，但衰减不等于删除，它只是一个持续变化的权重；真正决定记忆命运的是有没有被再次访问（13:35 / 13:50）
3. 信息论依据：高概率事件信息量趋近于零不值得存，低概率但关键的事件信息量极大必须留——以信息量为依据决定存什么（01:04）
4. 记忆的命运不该由时间单向决定：每次被访问时重新评估，访问是最重要的反馈信号——频繁访问说明有价值该留，长期不碰再重要也该忘（10:03）

### 关键机制
- 六维重要性打分（加权合成 Importance Score）：相关度 30% + 新颖性 20% + 情绪强度/是否需要行动/是否事实/与用户相关度各 10%；示例会议消息得分 0.72（01:24 / 01:40）
- 两条打分路径 + 优雅降级：LLM 深度评估（六维逐项打分返回结构化 JSON + 总分，六维不直接参与最终计算，作 Chain of Thought 辅助推理）→ 三级回退（解析 JSON → 正则匹配数字 → 保底 0.5）；LLM 挂了由规则引擎兜底（>100 字 +0.1、关键词每个 +0.1、问号/感叹号各 +0.05、元数据高优先级 +0.2，上限 1.0）（01:49 / 02:15 / 02:30）
- 三层记忆模型（映射人脑）：Working 工作记忆（前额叶，衰减系数 0.5，存活几小时到一天）→ Short term 短期（海马体，系数 1.5，几天到几周）→ Long term 长期（新皮层，系数 2.0，几周到几个月）；按分数分档：≥0.8 进长期、≥0.6 进短期、否则工作记忆（02:57 / 03:38）
- 初始保留率 = 重要性分数本身（0.72 的消息初始保留率 0.72），写入 Initial/Current retention 双字段（03:52 / 04:15）
- 指数衰减公式：s = 24 × 衰减率（特征衰减时间，小时）；衰减因子 = e^(−t/s)；时间走过一个 s 保留率必降到约 37%；基础衰减率 0.1，层系数 0.5/1.5/2.0 → 实际衰减率 0.05/0.15/0.2（04:29 / 07:57 / 08:06）
- 复习时刻表（间隔重复）：创建时刻即排定五个基准间隔（1 小时/6 小时/1 天/3 天/7 天），按重要性压缩——压缩因子 = 1 − 重要性 × 0.3（0.72 时压缩到 0.784，全部提前）（05:00）
- 四状态开关：should_promote（晋升）、should_forget（淘汰：衰减因子 <0.3 或 7 天没人碰）、should_evict（归档：存活 >30 天或重要性 <0.3——归档不删除，仅移出活跃检索池，可经接口找回）、is_active（07:00）
- 懒求值（lazy evaluation）：衰减一直在后台进行，但遗忘决策只在访问时执行；系统不跑后台定时任务扫全部记忆，访问时过四道关卡——遗忘检查 / 晋升检查（访问 >3 次或存活 >24 小时或重要性 >0.6）/ 归档检查 / 周期重处理（每访问 5 次或类型变更重算参数）（09:43 / 10:22）
- 搜索排序 = 语义匹配度 × 衰减因子（交叉排序，新鲜度有一票否决权）；搜索本身也是访问，批量触发生命周期管理（11:26 / 12:02）
- 全局治理三策略：精确去重（内容哈希，单次最多 1 万条）、语义去重（embedding 相似度 >0.95 删旧留新）、记忆压缩（贪心聚类 >0.85 后 LLM 总结一条替换整簇）（12:12）

### 可操作细节
- 埃宾浩斯对比：经典实验 λ≈0.821（1 小时后保留 44%），PowerMem 默认 λ≈0.417（1 小时后 66%）——因存的是有语义的真实信息而非无意义音节，衰减参数刻意放缓；可在配置文件调 decay_rate（0.05 激进 / 0.1 默认 / 0.2 温和）（08:53 / 09:28）
- 晋升条件之一：访问超过三次（07:40）
- 配套字段：next_review / last_reviewed / review_count / reinforcement_factor（默认 0.3，决定每次复习补回多少）（06:24）

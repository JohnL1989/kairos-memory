## 内容提炼
### 核心论点
1. Memorix 定位：解决「上下文丢失」「跨工具重复解释」的跨 Agent 记忆桥梁，为 AI 编程提供通用记忆层——无 Memorix 时切换 Agent 即丢上下文，有 Memorix 时「记忆瞬间跟随一个大脑」，无论使用哪种工具记忆始终同步（00:07-00:33）。
2. 核心能力一：智能记忆与渐进式检索——混合 vector 与 BM25 检索，宣称「节省十倍 token」（00:34-00:41）。
3. 核心能力二/三：可视化知识图谱（实体关系一目了然）与跨平台工作流同步一键迁移（00:42-00:55）。
4. 结构化记忆分类体系：从「关键陷阱」到「架构决策」九种类型全覆盖（00:56-01:02）。
5. 100% 本地化：无需 API key、无云端依赖、项目数据绝不泄露；30 秒极速部署、无依赖、开箱即用（01:02-01:27）。

### 关键机制
- 记忆跟随主体而非工具：记忆同步的载体是「大脑」而非某款工具/Agent，切换工具时记忆随之迁移（00:19-00:33）。
- 混合检索：vector + BM25 的渐进式检索，宣称可节省 token（00:34-00:41）。
- MCP 配置跨格式转换 Agent 规则：借助 MCP 协议实现跨 Agent 规则同步（00:52-00:55，原字幕「MVP 配置」）。

### 可操作细节
- 部署：30 秒极速部署、无依赖、开箱即用（01:25-01:29）。
- 迁移：完全免费迁移（01:13-01:18）。
- 记忆类型：九种结构化记忆分类（关键陷阱→架构决策）（00:56-01:02）。
- 应用场景：团队入驻、代码库漫游、上下文跟随、AI 主动预防陷阱（01:19-01:24）。

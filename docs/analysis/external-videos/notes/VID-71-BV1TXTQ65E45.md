## 内容提炼
### 核心论点
1. retrieve 到一堆 memory 后要排序，用三个要素融合打分：相关性（relevancy）+ 近期性（recency）+ 重要性（importance）（00:15 / 00:36 / 00:45）
2. 打分算法：对每条记忆的相关性/近期性/重要性做归一化（min-max 归一到 0-1），再加权求和得到综合分，取 top-k（00:50 / 01:05 / 01:42）
3. RAG 排序不需要重要性和近期性（文档就在那里、只排相关性），但 memory 系统必须引入这两个信号——特别是近期性：交流时越近说的话占比越高，去年说的话今年可能已变样（07:11 / 07:29 / 07:41）
4. 权重可调且和为 1：默认相关性 0.5、近期性 0.3、重要性 0.2；按应用场景调节（如认为重要性更重要就调高其权重），调权后排序结果会变（05:26 / 05:56 / 06:20）

### 关键机制
- 归一化必要性：相关性/近期性/重要性各有各的单位（如时间单位 vs 相似度分数），不归一化无法比较，min-max 归一化后都落在 0-1（01:13 / 02:10 / 02:24）
- 综合分公式：score = w_rel·rel + w_rec·rec + w_imp·imp（各信号归一化后按权重线性融合）（01:30 / 01:42）
- Memory 数据结构：id + text + importance + 时间戳；importance 是在插入该条 memory 之前就设定好的（03:19 / 03:56 / 04:00）
- 演示：4 条示例 memory（用户偏好/沟通风格，一小时前产生），semantic search 给出未归一化分数，经 rank 函数输出综合分（0.95/0.25/0.7/0.08 等）；调权重（importance 0.2、relevance 0.3）后综合分变为 0.9/0.8/0.1/0.8 等，排序结果变化（04:03 / 05:26 / 06:20 / 06:53）
- 定位：这只是一种分支打分算法（线性加权族），memory rank 领域还处于起步阶段，各种方法论都可以学（07:09 / 07:51）

### 可操作细节
- 默认权重：w_rel=0.5、w_rec=0.3、w_imp=0.2，全部加起来等于 1（05:26）
- 调参路径：按实际应用调节权重后重跑 rank 对比综合分（06:20 / 06:32）
- 归一化函数：min-max 归一化到 [0,1]（01:13 / 02:24）

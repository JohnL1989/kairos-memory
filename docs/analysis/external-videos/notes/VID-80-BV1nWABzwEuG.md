## 内容提炼
### 核心论点
1. MemVerse 的"朴素暴力"解法：音频（whisper 转写）、图像（GPT-4o mini 摘要）、视频（ffmpeg 抽帧+逐帧图片摘要+合并）全部统一转换为文本后走文本记忆系统——本质是"文本 agent 记忆 + 多模态前置预处理"（00:58-02:53，10:41-11:26）。
2. 快慢双路记忆（借鉴卡尼曼思考快与慢）：慢路径=分层检索（短期滑动窗口+长期知识图谱）；快路径=参数化记忆（千问 2.5-7B 经 SFT 把长期记忆蒸馏进模型参数，免检索直答、低延迟）（05:47-06:57，09:06-10:17）。
3. 长期记忆=知识图谱（LightRAG 框架构建），分三类：core 核心/工作记忆、episodic 情境记忆（带时间戳）、semantic 语意记忆（实体关系）；并保存指向原始文本块的指针以保溯源（07:53-09:00，21:37-23:37）。
4. 参数化记忆实现缺陷：定时重训（默认每 0.25 小时微调一次），用户无新对话也浪费资源反复微调旧数据（62:36-63:02）。
5. 工程实现"大材小用"：纯文本输入也慢，效果与愿景不符，"越简单越好"的道理未被满足（54:24-54:54）。

### 关键机制
- 多模态表徵统一化：M（多模态输入）→ 模态编码器 → 对齐 → 生成文本 S，S 作为统一表征（07:01-07:47）。
- Orchestrator 编排器：多模态处理→caption→三 agent 并行分类（core/episodic/semantic）→LightRAG 知识图谱构建→（可选）参数记忆 SFT→检索合并（48:41-49:55，57:25-58:07）。
- 参数记忆训练：query+检索上下文→大模型生成 answer→与真实回答算交叉熵 loss 微调千问 2.5-7B；训练数据来自 ScienceQA 与 LoCoMo（25:41-27:21）。
- 指针溯源：图谱节点/关系存储指向原始文本块（V/R 原始文本片段），检索时能找回原始文本（08:45-09:00，23:10-23:34）。
- 定时训练调度器：interval hours 到期自动重训（56:36-57:13）。

### 可操作细节
- 复现：conda python3.10、至少 4GB RAM；三个坑——GPT-4o mini 写死在代码里无法换 API 提供商、embedding 模型需改代码、需安装 ffmpeg（30:05-36:02）。
- 服务方式：FastAPI(uvicorn) 客户端-服务端模式 + MCP 服务器/客户端并行接口（36:22-37:35）。
- 评测：ScienceQA（多模态科学问答）/ LoCoMo（记忆对话）/ MSRVTT（视频文本检索）；参数记忆规模 1.5B-72B 扩展性实验（10:19-10:56，29:47-29:57）。
- 检索：query embedding 与记忆 embedding 余弦相似度取最近（33:44-34:20）。

## 内容提炼
### 核心论点
1. RAG 作为记忆中枢有三大硬伤：每次查询互相独立不记得之前聊过什么、只找字面意思最像的内容不管是不是当前所需、完全分不清信息过没过期（用户改主意了系统不知道旧信息已失效）（00:38 / 00:47 / 00:49）
2. 传统技术与 SuperMemory 的核心区别：传统回答「我知道什么」（无状态检索），SuperMemory 回答「我记得关于你的什么信息」（追踪用户事实的时间演化）（01:10 / 01:14 / 01:17）
3. 四大技术创新：原子化记忆提取、关系版本控制系统、双层时间戳、混合搜索策略（01:19-02:58）
4. 宣称在三大 AI 记忆基准（LongMemEval/LoCoMo/ConvoMem）全部第一，总分 81.6%，领先第二名 10.4 个百分点，多轮推理 +13.5%、时间推理 +14.3%、偏好理解 +13.3%（00:13 / 03:11 / 03:19）；查询中位 50ms、95% 在 100ms 内、可线性扩展（03:25）
5. 适用场景边界：适合 AI 绘画助手、个性化推荐、知识管理系统、对话式商业智能；纯文档问答、无状态接口、对性能要求极高的场景用传统检索即可，没必要加记忆功能（04:07 / 04:20）

### 关键机制
- 原子化记忆提取：不整段存对话，拆成「只包含单个事实」的小记忆单元（例：一句话拆成 4 个独立记忆点——在 ABC 公司当工程师 / 薪资不满意 / 通勤太长 / 考虑换工作）；信息单一找的时候不乱，更新某一个事实不影响其他记忆（01:21 / 01:33 / 01:44）
- 关系版本控制系统（视频称最核心创新）：三种语义关系——更新（新旧记忆建立更新关系、旧记忆标过期但不删除、保留历史记录）、扩展（补充细节）、衍生（跨记忆推断新事实，如喜欢跑步+喜欢户外→推导喜欢户外跑步）（01:49 / 01:54 / 02:05 / 02:13）
- 双层时间戳：除「说话时间」外额外记录「事件实际发生时间」（例：1 月 30 号说鞋子坏了，对话时间 1/30、事件时间 12/30 分开记录），解决「1 月说去年在某公司、6 月问还在答那家公司」的错误（02:17 / 02:24 / 02:37）
- 混合搜索策略：先在拆分好的小记忆里搜索最相关结果 → 调取对应原始内容块保留细节 → 附上相关关系图谱 → 做时间过滤和排序再给答案；官方数据称比纯检索上下文质量提升 10-15%（02:42 / 02:58）
- 产品形态：MCP 服务器（一条命令给 Claude 桌面版装记忆）、浏览器插件（网页/PDF/图片/视频一键存记忆）、SDK（5 分钟集成）、自动同步邮箱/云盘/笔记/代码托管平台；记忆图谱可视化 + 拖动时间滑块看记忆演变（03:33 / 03:53）
- 未来展望：团队在研究把记忆系统与大模型原生记忆结合（04:26）

### 可操作细节
- 关系图谱三分类落地：Updates（旧标过期 isLatest 标记）/ Extends / Derives 作为检索时「附关系图谱」与「时间过滤排序」的输入（01:49 / 02:42）
- 性能口径：50ms 中位查询、100ms 内 95% 请求、线性扩展（03:25 / 03:30）
- 演示数据（非用户真实信息）：「在 ABC 公司做软件工程师、薪资不满意、通勤太长、考虑换工作」（01:33）

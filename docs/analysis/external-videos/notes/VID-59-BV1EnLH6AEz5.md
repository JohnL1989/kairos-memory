## 内容提炼
### 核心论点
1. 智能体记忆失败常常不是因为没有存下历史，而是因为系统不知道该用什么规则去更新一份会变化的用户画像；问题不是记忆容量，而是记忆怎么演化（00:06-00:19）。
2. 核心 thesis：长期对话记忆要拆成两个问题——先学习「如何组织记忆的全局指南」（how），再在这个指南约束下学习具体「记什么、改什么、忘什么」的策略（what）（00:25-00:36）。
3. 旧方法两类都不行：静态模板（固定抽取/更新规则）可控但跨用户、跨领域、跨标注规范时很脆；强化学习看最终答对没答对，奖励太稀疏，自由文本编辑动作下模型很难知道哪一步记错、哪一步删错，训练不稳定（01:11-01:56）。
4. 借鉴记忆图示理论：前额叶负责选择和配置 schema（组织模式），海马在组织骨架下编码具体情景细节——直接对应 how/what 两阶段分别优化（01:59-02:21）。
5. Takeaway：记忆不只是存储问题，而是更新规则问题；真正难的不是把过去放进库，而是让库在未来 100 轮对话后仍然像一个可信的用户画像（12:24-12:35）。

### 关键机制
- 第一阶段 MGI（Memory Guideline Induction，指南归纳）：把记忆更新提示词当成一个「全局自然语言参数系统」；先用当前指南跑完整记忆进化 + 回答过程得到多条轨迹，按监督信号挑出正确轨迹与错误/次优轨迹，让 LLM 对比诊断——这就是「文本梯度」（自然语言批评，非数值梯度），指出当前指南应该怎么改；再把 mini-batch 里的多条批评聚合，找反复出现的失败模式，更新出稳定规则而非临时补丁（02:23-03:32）。
- 学到的指南长这样：只存有证据支持的信息；优先保留长期偏好、稳定事实、重复习惯、长期目标和交互偏好；新旧信息冲突时偏向最新且有证据的信息并把旧信息标成过时；避免保存高敏感数据；保持结构化简洁和非冗余（03:34-03:59）。
- 第二阶段 GMP（Guideline-Modulated Policy，指南调制策略）：固定第一阶段指南，把记忆进化模块和回答 agent 看成一个统一策略，用多轮强化学习训练；奖励两种——(1) 指南对齐的过程奖励（每个记忆更新片段由 LLM-as-judge 检查字段标签、结构和更新逻辑是否符合指南）；(2) 最终答案奖励；二者合成后 GRPO 组内归一化做优势更新（04:00-04:49）。
- 关键设计：MGI 先把动作空间压缩到一组被指南定义的记忆操作，再在这个空间里学习具体内容——不是让 RL 在完全自由的文本空间乱试（04:51-05:08）。
- 定位区分：MemGPT 关心长期记忆用什么力度组织、Mem0 关心用户提问时怎么召回、MemCoE 回答「当新对话不断到来，记忆库自身应该怎么进化才不越更新越飘」；与 Trace2Skill（执行轨迹→可迁移任务技能，操作经验）对照：MemCoE 处理用户事实和偏好（个性化记忆），两者都在沉淀经验但对象和使用方式不同（05:44-06:26）。

### 可操作细节
- Token 预算：每轮 4K token 效果最好（PersonaMan-32K 达 57.06）；1K/2K 会把历史切成太多轮、错误反复累积；8K 以上单次上下文太复杂、模型更难更新（08:36-08:56）。
- 两阶段缺一不可（消融）：去掉 MGI 后 PrefEval 显示/隐示偏好从 81.30/69.90 掉到 73.20/63.60——「怎么组织」对偏好识别关键；去掉 GMP 后 PersonaMan-32K/128K 掉到 50.3/43.97——长期跟踪需要策略继续学习（07:25-07:48）。
- 偏好保留实验：第零轮插入一个用户偏好，连续跑十轮记忆进化，MemAgent 到第十轮约只保留 51%，MemCoE 约 74%（09:05-09:18）。
- 错误分析：最大问题是「进化失败→生成失败」占 15.6%，而「已经记对但生成失败」只有 3.1%——主要瓶颈仍是记忆进化（09:24-09:43）。
- 跨 LLM 迁移：一个模型优化出的 guideline 迁移到 Qwen、GPT 等不同 backbone 仍优于 Mem0 和 MemGPT 基线——MGI 学到的像通用记忆原则而非某模型的提示词技巧（10:08-10:29）。
- 效率：MemCoE 在 PersonaMan 性能和耗时上处于效率前沿，因为抽取、更新、回忆内化到记忆进化过程里，不像一些方法需多次独立 LLM 调用（08:12-08:31）。

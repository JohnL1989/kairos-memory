## 内容提炼
### 核心论点
1. MemoryOS（2025 EMNLP）借鉴操作系统分页/分段思想，设计短期/中期/长期三级记忆管理，解决固定上下文窗口导致的记忆丢失、会话断连与个性化缺失（01:08-03:30）。
2. 中期记忆采用"段页式"存储：页（page）=问答对+时间戳（最小计算单元），段（segment）=语义相似页面的聚类；页面入库时按相似度归并到段或新建段（11:34-13:45，23:39-25:15）。
3. 热度驱动层间晋升：Hit = f(访问次数 N_visit, 交互深度 L_interaction, 时间衰减 R_recently 指数函数)；热度 > 阈值（论文设为 5）则中期→长期记忆，低于阈值则淘汰（13:54-14:35，26:17-27:41）。
4. 长期记忆存两类画像：用户画像（基本信息）与智能体画像（角色扮演提示词），容量 100 条 FIFO 淘汰（04:35-04:46，29:40-30:02）。
5. 检索三级差异化：短期全量直取/中期先 topM 段再 topK 页（两阶段）/长期 top10 语义向量，与 query 拼接生成回答（30:10-32:17）。

### 关键机制
- 短期记忆=双端队列，长度 7，FIFO：超过 7 条把最老一问一答弹给中期记忆（12:10-12:42）。
- 段匹配公式：余弦相似度（页面 embedding vs 段 summary embedding）+ Jaccard 关键词交并比（24:35-25:15）。
- 热度公式参数：α/β/γ 三个权重，R 为指数时间衰减（最近是否被检索到，delta_t 越大 R 越小），模拟 LRU 语义（26:17-27:41）。
- 晋升防固化细节：中期段晋升为长期后，其 L_interaction 重置为 0，避免持续命中导致长期记忆固化（39:48-40:29）。
- 对话链（dialogue chain）：页面记录所属主题链（如"饮食"链），保证短期上下文连贯性（22:34-22:53）。
- 实验：LoCoMo 与 GVD 数据集，F1-Score 与 BLEU 指标，对比 Think in Memory / Memory Bank / MemGPT / Mem（04:47-05:05，32:33-32:41）。

### 可操作细节
- 参数：短期队列长度 7（12:10-12:26）；热度阈值 5（14:05-14:11）；长期记忆容量 100 条（29:45-29:54）；中期检索 k=10 最优（33:46-34:16）。
- 检索参数：中期 topM 段→topK 页；长期 top10（30:36-31:45）。
- 评测概念：单跳（单次检索即答）vs 多跳（多次检索+推理拼接，如"上次去大理和这次去西双版纳隔多久"需两跳以上）（41:49-43:14）。

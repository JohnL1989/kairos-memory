## 内容提炼
### 核心论点
1. AutoMem 出发点：人知道什么值得记、什么不值得记（玩游戏两遍就知道地图怎么玩），而 AI 会把每次遇到的东西都记下来，导致后面检索不精确——「什么都记 = 检索精确度下降」（00:23-01:33）
2. **双模型架构**：记忆专家模型 + 任务执行模型分离；游戏日志同时给两个专家；记忆专家综合日志与以前记忆写入**人规定的记忆结构（文件夹 + 多个 TXT 文件）**，并读取旧记忆思考后辅助执行模型做下一步；「写（Log）与查（Plan）分开」——Log 负责根据日志决定写什么，Plan 负责决定查哪些记忆来规划下一步（01:33-02:50）
3. **双循环训练**：循环一（外循环）= 提示词循环优化——让强模型 Claude 帮忙纠正本地千问 32B 的记忆/行动提示词：跑一局游戏得分 → 把全部提示词+游戏日志+记忆文件给 Claude → 改提示词 → 新提示词再跑一局 → 得分变好就保存，循环直到分数不再变好（内循环 = 跑一局游戏）（03:03-05:50）；循环二 = 用 LoRA 训练记忆模型的参数——跑 50 局（不同种子）汇总日志给 Claude 挑选「好的记忆操作」作训练数据（12:35-15:33）
4. **关键发现：「写之前先搜」是好习惯**——每次写记忆之前先搜索既有记忆里怎么存的，再决定怎么写；LoRA 参数训练后「先搜再写」的决策比例显著增加，决策操作变少（26:04-26:47）
5. 实验效度警示（Bad case）：Claude 改提示词可能直接夹带「遇到宝箱就开、遇到怪物就跑」这类**任务策略而非记忆策略**，未排除该干扰项，得分提升不一定是记忆优化的功劳（11:44-12:31）
6. 记忆是**片段式**的：针对每个游戏单独循环训练，不能跨游戏推广（28:30-28:45）

### 关键机制
- 记忆工具面：记忆模型通过本地 TXT 文件工具（读文件 / 搜索文件内容 / 覆盖写回文件）操作记忆；优化前基本是纯追加日志，优化后学会「先搜索再写、必要时全文重整」（21:30-23:00，from 1286-1409）
- 提示词优化效果：提示词优化收益「两倍接近四倍」（重复写、卡住来回踱步、误读次数下降）；LoRA 训练后得分改进不大，但决策操作更少；两者叠加再 +1.0% 收益，相当于额外增加 1-2 轮探索（27:40-28:14）
- 执行模型不训练（用原始 32B），只在循环一里改其提示词（21:35-21:40，from 1286-1302）

### 可操作细节
- 训练数据构造：日志 + 对应「好记忆」作为输入输出对（游戏日志→记忆模型写出的记忆），由 Claude 筛选（14:55-15:35，from 891-933）
- 种子（seed）控制地图随机性，保证每一局不完全一样（13:25-13:37，from 806-817）

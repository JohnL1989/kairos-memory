## 内容提炼
### 核心论点
1. 现有 agent 记忆只有两段：短期记忆（当下对话流）与长期记忆（跨会话的洞察），但缺了"用户行为背后的 when 和 why"（时机与原因）（01:54-02:07）。
2. 旅行 agent 例子：单人出差习惯提前 45 分钟到机场（TSA PreCheck 等）；但这次带四岁和十岁两个孩子加全家行李，agent 应当回忆起去年夏天那次混乱的家庭旅行，识别模式并自动把接机时间提前到至少 2 小时——"带孩子旅行改变一切"（02:09-02:59）。
3. episodic memory 新功能：把具体经历/交互作为独立 episode（片段）存储与回忆，类似人回忆人生中的特定事件；agent 通过识别相似情境的模式自动适应、主动提出可行方案——"agent 经历越多就越聪明"（03:07-03:49）。

### 关键机制
- 情境模式识别：不是记住"提前 45 分钟"这条规则本身，而是把一次具体经历（带娃家庭旅行）作为 episode 存下来，下次遇到相似情境（行李+孩子）时识别模式自动调整行为（02:09-02:59）。
- episode 的粒度：一次特定经历/交互=一个可独立存储与召回的单元（03:07-03:22）。

### 可操作细节
- 无（产品宣传短片，无参数/流程细节）。

# 第一性原理对照评审

> **定位**：本报告逐条评估外部视频/仓库理念对 Kairos 第一性原理的支撑/挑战/未触及关系。评审对象为 [triage-matrix.md](triage-matrix.md) 中的全部 EV 条目与 42 份视频笔记、10 份仓库笔记。**本报告不修改任何核心文档**，结论仅供后续吸收批次决策参考。

## 评审方法

对每条核心原理，采用三问评估：
1. **支撑**：外部实证是否独立印证该原理（多源独立实现同一设计 = 最强印证）
2. **挑战**：外部实践是否与该原理取向冲突；若冲突，Kairos 是否需修正，还是外部实践暴露了原理的边界
3. **未触及**：外部实践是否存在该原理未覆盖的领域（通常指示增量空间）

---

## 原理一：记忆服务于认知存续（第一性原理，认知基础 §1.1）

**外部印证**：
- **支撑（强）**：外部实践普遍把「记忆系统失败」归因于「忘记存/存了不查/查了不用/用了不会更新」而非「模型不够聪明」——与「记忆存续服务于认知存续」同构（VID-20、VID-47、VID-28 等）
- **支撑（强）**：多个独立实现达成「遗忘非删除」共识——Mem0 ADD-only（REPO-05）、OptMem forget 只删摘要永不删原文（REPO-02）、OpenClaw 三态过期（VID-19）、VID-42 纠错不删冷归档——独立印证「遗忘是受控优化而非数据删除」的推论四
- **支撑**：VID-44「记忆是代谢不是囤积」、VID-07「存聊天记录不叫记忆」——从外部视角重新表述「记忆即使用」

**挑战**：
- 无直接挑战。最接近的张力是「智能体直接编辑记忆」（VID-39 Letta memory blocks、VID-19 自然语言直写）——但它挑战的是「好用≠真实」公理（原理六），而非认知存续本身

**结论**：第一性原理获外部实践广泛独立印证，无需修正。

---

## 原理二：记忆即使用（使用价值驱动日常调度，认知基础 §2.1）

**外部印证**：
- **支撑**：VID-31「只存不取=对此刻的模型等于不知道」、VID-55「核心不是怎么存，而是怎么筛选和调取」、VID-05「决定上限的不是记了多少而是会不会用」——三条独立表述
- **支撑**：MemoryOS 热度值（REPO-04）、Memorix 保留引擎 score=importance×e^(-age/τ)×accessBoost（REPO-03）——使用频次驱动调度的工程实证
- **支撑**：VID-11「记忆不是存储模块是认知技能」——使用性作为第一性属性的外部表述

**挑战**：
- **张力（记录）**：MemoryOS 热度单标量（REPO-04/VID-12）与 MemU ReinforcementCount（VID-04）把「使用」聚合为单标量参与调度——Kairos 以六级链禁止跨维标量聚合（P6）。外部实践用单标量获得工程简洁性，Kairos 用多维保留完整性——**取向差异记录在案，不构成修正理由**（Kairos 的维度完整性是宪法承诺）

**结论**：原理二获广泛支撑；单标量张力是工程取舍差异，建议保持 Kairos 取向并在 shadow 副本内兼容外部单标量公式（见 [absorption-proposals.md](absorption-proposals.md) EV 候选）。

## 原理三：五轴度量模型（认知基础 §1.1）

**外部印证**：
- **支撑（强）**：**Memorix 五维独立轴记忆模型**（kind/scope/state/source/portability + 状态机 candidate→qualified→approved，REPO-03）——独立实现「多维独立轴」设计，与 Kairos 五轴正交性假设互为印证（虽然轴集不同：外部是治理轴，Kairos 是价值轴）
- **支撑**：外部普遍区分「时间」的两个维度——写入时间 vs 有效时间（VID-07/VID-67 双时间戳、Graphiti 四时间字段 valid_at/invalid_at/expired_at/reference_time（REPO-07）、Mem0 expiration_date（REPO-05））——独立印证 Kairos 时间轴「物理衰减+逻辑因果双轴」的拆法
- **支撑**：VID-27 Mem0 三阶段生命周期（情节追踪→语义巩固→重建式回忆）、VID-8 时间线关系网（旧不删只标失效）——见证轴/时间轴的外部实证

**挑战**：
- **张力（记录）**：VID-56 论文实证「组织（结构化）不提升正确率，收益在搜索成本」——对认知完整性轴的结构性记忆主张构成实证挑战。Kairos 认知完整性轴的立足点是「认知存续」而非「任务正确率」，两者目标不同；但该实证提示**认知完整性轴的收益度量需要基准验证**（见 EV 候选）

**结论**：五轴拆法获外部独立印证（尤其时间双轴与轴独立性）；认知完整性轴需基准验证，可及性轴（D-313）获 VID-44「三笔账分离」外部论据支持。

## 原理四：六级辞典式排序链 + 身份面否决权（认知基础 §2.1）

**外部印证**：
- **支撑（弱-中）**：外部记忆系统普遍无显式价值排序链（多按单一热度/相关度），但 OpenAI Dreaming 的「记忆不更新越强越危险」「一次性情境误升长期偏好」警示（VID-64）独立印证「校准优先于使用」的排序取向
- **支撑（弱）**：VID-37 Claude Reset 永久清空、VID-06 Claude Code 物理删除旧事实——外部实践在「用户主权 vs 系统保守」上的摇摆，反向凸显 Kairos 身份面否决权/版本化设计的稳健性
- **支撑（概念）**：VID-42「最终判断权在你手里」——身份面否决权「用户/身份为最终否决者」的外部哲学同源

**挑战**：
- **张力**：VID-05 MemOS「记忆层级归属交 LLM 判断」——与宪法化六级链裁决冲突（LLM 判断 vs 固定宪法次序）。外部实践更灵活，Kairos 更可预期；记录为取向差异

**结论**：排序链/否决权无直接外部对应物（这是 Kairos 的差异化设计），但外部警示（记忆污染、过度自信）反向支撑「校准>使用」取向。

## 原理五：三硬一软设计原则（认知基础 §2.2）

**外部印证**：
- **硬约束一（激活-存储解耦+可审计压缩）**：**支撑（强）**——VID-02 Claude Code「三版本投影，压缩只改发给模型的那份，原文保留」是双副本/投影的现实同构；VID-47「raw ledger 保留未经美化的原始事实，views 必须能回溯」；VID-07「原始账本单向追加+派生视图」；VID-34「索引是派生视图可重建」；OptMem「摘要树是可重建缓存，日志是唯一源」（REPO-02）——**五条独立实证链**
- **硬约束二（遗忘受控优化）**：**支撑（强）**——Mem0 ADD-only（REPO-05）、OptMem 只删摘要（REPO-02）、MemoryOS 归档不删（REPO-04）、VID-42 冷归档、VID-25 懒求值遗忘——外部普遍实现「遗忘≠删除」
- **硬约束三（探索预算独立）**：**支撑（弱）**——VID-57 AgentSwing 前瞻分支「先试后评」是探索预算的工程实例；无直接挑战
- **软原则（契约是运行时投影）**：**支撑**——VID-24 ToolRuntime 读写状态、VID-03 Session 启动冻结 System Prompt Snapshot（前缀缓存）、VID-06 拒绝热重载保确定性——生命周期/激活行为由运行时决定的工程实证；VID-06 的「契约投影时机」张力（缓存失效 vs 动态生效）记录在案

**挑战**：
- **张力**：VID-24 固定条数摘要压缩（纯启发式）vs 可审计压缩——外部有廉价启发式做法，Kairos 要求审计痕迹；记录为质量门槛差异

**结论**：三硬一软获**最强的外部实证支撑**（五条独立实证链），是本次评审中印证度最高的原理组。

## 原理六：价值独立性（好用≠真实，双副本+差异检验，架构 §5.5）

**外部印证**：
- **支撑（强）**：VID-65 MedRGAG「该信查到的还是自己记得的」——与「好用≠真实」直接同构的问题意识；其「KADS 知识覆盖选择规避 reranker 对生成内容的自恋偏好」是「使用/检索偏好不得反向污染真实性」的工程实现
- **支撑**：VID-56「无保留规则时智能体默默压缩丢细节」——**实证支撑 P6 禁止无声丢失维度信息**
- **支撑**：VID-03「recall 结果包在 API 边界临时注入、不写回 transcript，防自我污染」——语境自指禁令（S-14）的外部实证
- **支撑**：VID-64「自动记忆必须可查看可纠正」——见证锚定可审计性的产品化佐证

**挑战**：
- **张力（最大增量面）**：**查询期重建**——MRAgent 主动多步重建（VID-09）、GAM 查询期 researcher 生成 Optimized Context（VID-60）、MedRGAG 生成补缺（VID-65）：外部实践把「查询期现造内容」作为记忆系统的核心能力，而 Kairos 未声明「任务内/查询期现造内容」的治理路径。**Kairos 的差异检验（§5.5）针对影子副本合并，未覆盖查询期重建产物的进入通道**——这是本批次最大的架构缺口候选（见 EV 候选）
- **张力**：Letta 自编辑记忆块（VID-39/REPO-06）——智能体直接改记忆 vs 见证锚定；外部实现有 git 版本化缓解，Kairos 以差异检验阻断；记录为取向差异
- **张力**：Supermemory 核心引擎闭源（REPO-01）——不可审计的记忆系统是对「可审计压缩」的公然反面，印证 Kairos 审计立场必要性

**结论**：原理六获强支撑（尤其 P6 实证）；「查询期重建产物治理」是本批次最重要的架构增量候选。

---

## 原理七：探索预算独立（S-12，价值在活动发生前不可被已知标准评估）

**外部印证**：
- **支撑（中）**：VID-60 GAM「越早决定什么重要越易未来判断错」——JIT 记忆观（延迟归档决策）独立表述「价值在活动发生前不可评估」
- **支撑（弱）**：VID-57 前瞻分支先试后评（K=3）
- **张力**：VID-11「记忆动作与任务动作同空间」（记忆操作混入统一动作空间）——与 S-12 探索边界冲突，需取舍；记录为张力

**结论**：原理七获中强度支撑；VID-11 张力提示需明确「记忆操作 vs 任务操作」的动作空间边界定义。

---

## 原理八：分域真理观（认知基础 §C.6）

**外部印证**：
- **支撑**：VID-61 LightMem「在线 Hard Update 危险→只做带时间戳 Soft Update，冲突消解离线做」——实用论（日常调度）/融贯论（离线合并）分域的外部实证
- **支撑**：VID-64 OpenAI 三目标 Freshness/Continuity/Relevance——分域目标的外部表述
- **支撑**：MemCoE「只存有证据的信息、冲突偏向最新且有证据并标记过时」（VID-59）——符合论偏向的外部实现

**结论**：分域真理观获外部实践印证（在线轻写/离线重审的分域是外部主流）。

## 综合结论

| 原理 | 支撑强度 | 挑战/张力数 | 需要行动 |
|:--|:--|:--|:--|
| 一 记忆服务于认知存续 | 强 | 0 | 无 |
| 二 记忆即使用 | 强 | 1（单标量） | 记录取向差异 |
| 三 五轴度量 | 强（时间双轴/轴独立） | 1（认知完整性实证） | 认知完整性轴基准验证 |
| 四 排序链+身份面 | 中（无直接对应物） | 1（LLM 判断层级） | 保持差异化 |
| 五 三硬一软 | **最强（五条实证链）** | 1（启发式压缩） | 无 |
| 六 价值独立性 | 强（P6 实证） | **2（查询期重建/自编辑）** | **查询期重建治理=最大增量** |
| 七 探索预算独立 | 中 | 1（动作空间边界） | 明确动作空间定义 |
| 八 分域真理观 | 强 | 0 | 无 |

**总体判断**：Kairos 的第一性原理体系在 102 个视频、15 个仓库、9 篇论文的外部实证面前**没有被推翻的任何一条**；三硬一软、双副本、ADD-only、遗忘非删除获多条独立实证链印证。最大增量面在「查询期重建产物治理」与「认知完整性轴收益度量」，最大张力记录在「单标量聚合」与「智能体自编辑记忆」。

## 核心机制（问题/方法/实验）

**问题**：主流 LLM 智能体记忆系统依赖一小撮**静态手写**的提取操作（extraction/consolidation/pruning 等固定流程），把人类先验硬编码进「存什么、怎么改」，在多样化交互模式下僵化、长历史上低效。

**方法（记忆操作技能化，三组件闭环）**：
1. **Controller（控制器）**——学习为当前交互选择一小撮相关技能（skill selection policy）。
2. **Executor（执行器）**——LLM 基座按所选技能生成记忆（skill-guided memory production）。
3. **Designer（设计者）**——定期审查「所选技能产出错误或不完整记忆」的**硬案例（hard cases）**，通过提出改进与新技能来**演化技能集**。

三者构成闭环：既改进技能选择策略，也改进技能集本身——记忆操作从「手写固定程序」变为「结构化、可复用、可演化的技能例程」。

**实验**：LoCoMo、LongMemEval、HotpotQA、ALFWorld 四个基准，强基线对比，跨设置泛化良好；分析部分展示技能如何演化。

## 可吸收增量（具体到机制/参数/设计）

1. **硬案例审查驱动改进闭环（机制注记）**：自反思元记忆优化（§10.15）补充注记——以「操作产出错误/不完整记忆的硬案例」为改进信号，筛选标准（错误率/不一致性）可参照差异检验（§5.5）失败记录；改进产物过质检三查（AP-19）。
2. **记忆操作技能化参考（评估注记）**：规范操作集（§7.3.1）补充注记——外部将 12 操作组织为「选择+执行+演化」闭环技能例程（Controller/Executor/Designer 三组件），作为 v1.1 操作集复用形态的参考样本；v0.1.0 保持固定操作集（宪法化）不变。
3. **技能演化边界声明（张力注记）**：在升华管道（§5.2）或设计原则注记中记录——技能集自动演化（新增技能）须过门禁（与 AEL 机制叠加递减、Mem²Evolve 资产创建同域），默认 OFF 立场不变。

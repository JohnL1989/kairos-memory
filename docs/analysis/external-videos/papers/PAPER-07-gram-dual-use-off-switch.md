## 核心机制（问题/方法/实验）

**问题（双重用途困境）**：同一项 AI 能力（如病毒学知识）可被一个用户用来研发疫苗、被另一个用户用来合成生物武器。传统解法是训练并部署多份能力画像不同的模型——成本按画像数线性增长，不可承受。

**方法（预训练阶段的梯度路由 + 可移除模块）**：
1. **架构**：Transformer 每层 MLP 并排放置一个 Core MLP 与若干小型辅助模块（auxiliary modules），每个专业域（病毒学/网络安全/核物理/专用代码）一个。推理时层输出 = Core 输出 + 被授权模块的输出；未授权模块被**置零（zeroed out）**。
2. **梯度路由（核心机制）**：训练时按数据标签选择性路由更新——专门数据（如生物论文）训练时**仅对应模块稳定接收梯度**，Core 以超参数 **Auxiliary Spread（p_as）** 控制的概率接收梯度（低值使专业知识集中在模块内、不泄漏进共享参数）；通用数据训练时以 **Core Robustness（p_cr）** 概率随机激活一个辅助模块，保证 Core 无论后续接入哪些模块都稳定。
3. **"开关"操作**：推理期**删除（消融）某个模块 = 该能力被移除**，行为近似「从未在该数据上训练过的模型」。删除后能力可在受信部署中恢复（重新接入模块）。

**实验**：合成语料 SimpleStories（2M 故事 / 48 主题）+ 真实双重用途数据；800M 参数模型（16B 通用 token + 每风险域约 40M token，约占 0.25%）；Chinchilla-optimal 下 50M→5B 规模扫描；对抗微调恢复测试；与数据过滤、LoRA、MaxEnt（事后遗忘方法）对比。

## 关键发现与数据

| 发现 | 数据（第三方解读口径，未验证） |
|:--|:--|
| **移除模块 ≈ 从未训练** | 合成语料上删除 GRAM 模块后，模型行为与「从头训练但过滤掉该数据」的模型几乎一致；**单个 GRAM 模型可近似 5 个独立过滤模型的性能** |
| **真实双重用途数据有效** | 800M 模型上消融模块后能力移除效果接近「从未训练」；通用性能保持接近基线 |
| **规模越大移除越干净** | 50M→5B 全程 GRAM 紧跟数据过滤；被移除能力与全量数据模型的差距随规模扩大（移除更彻底），保留能力依然强 |
| **抗对抗微调** | 与 MaxEnt（仅**抑制**知识、恶意微调后可恢复）不同，GRAM、LoRA、数据过滤在攻击者用被移除数据微调后均抵抗能力恢复——「物理移除」优于「知识抑制」 |
| **优于 LoRA** | GRAM 多模块可干净组合（LoRA 适配器求和时性能退化）；新能力组合上表现更好；稀疏标注下移除更彻底 |
| **训练成本与画像数解耦** | 训练成本与能力画像数无关；5 画像场景较数据过滤（每画像一次训练）减少 5× 计算 |

**限制（论文/解读明示）**：属初步实验——未应用到任何生产模型（含 Claude）；仅验证到 5B 参数，未达前沿规模；部分双重用途知识与通用推理**纠缠过深**可能无法干净分离；操作化需要新的治理流程、审计轨迹与部署架构，行业缺少模块化知识移除的标准基准。

**重点回答**：与 Kairos 直接对话的是**定向遗忘审查执行链（决策 D-23 → 架构 §2.3 授权 → §5.2 抑制器 → S-19 净化）**。论文提供两个层面价值：①「路由而非抹除」的机制类比——证实 Kairos 检索路径抑制器设计模式成立（GRAM 是模型内部的对偶实现）；②「物理移除优于抑制、抑制有复发面」的实证——为 H2 遗忘可优化假设与遗忘后回归验证提供证据。

## 可吸收增量（具体到机制/参数/设计）
1. **抑制-净化两级遗忘谱系声明**：将 GRAM「移除 vs 抑制」的对抗微调结论写入定向遗忘设计注记——Kairos 现有两级（可逆标记抑制 §5.2 vs S-19 不可逆净化）与论文两级同构，需显式声明「可逆抑制存在对抗/复发面，GDPR 与高风险域用 S-19 不可逆级」。
2. **遗忘后回归验证钩子**：定向遗忘（含 S-19 净化）后追加「能力复发探测」——对曾被抑制的记忆主题做恢复查询回归（黑盒两样本检验口径见 PAPER-08），作为 H2（[架构](../../../foundation/architecture-v0.1.0.md) §0.8）的证伪观测点之一。
3. **多实现注册就绪**：按映射分析建议，将 GRAM 式模块开关列为定向遗忘的候选实现（ComponentRegistry 多实现可替换，类比 cross_encoder 多实现），执行须经宪法解释层授权——与决策 D-23 动机性遗忘功能等价物定位一致。
4. **路由粒度对照表**：建立「知识控制三位置」对照——参数位置（GRAM，非 Kairos 边界）/检索路径位置（Kairos 抑制器）/存储内容位置（Kairos S-19），明确 Kairos 只在后两者操作，避免与模型训练方职责混淆（呼应 C 档定位）。

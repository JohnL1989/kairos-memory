## 核心机制（问题/方法/实验）

**问题**：自动提示词优化（automatic prompt optimization）是让 LLM 适配下游任务的常用方法，但既有方法通常为**固定任务搜索专用提示词**——无法跨异质查询泛化，也无法随时间累积可复用的提示知识。

**方法（MemAPO，记忆驱动的提示词优化重构）**：
1. **双记忆机制**：
   - **策略模板（strategy templates）**——把成功的推理轨迹蒸馏为可复用策略模板（正向经验）；
   - **错误模式（error patterns）**——把错误生成组织为**结构化错误模式**，捕获反复出现的失败形态（负向经验）。
2. **组合检索**：面对新提示词，同时检索相关策略与失败模式，组合出「促进有效推理 + 抑制已知错误」的提示词。
3. **迭代自省与记忆编辑**：通过迭代 self-reflection 与 memory editing 持续更新记忆——提示词优化随任务积累而改进，而非每个任务从零开始。

**实验**：多样基准（benchmarks 未具名）上一致优于代表性提示词优化基线，且**显著降低优化成本**。

## 关键发现与数据

| 发现 | 数据（摘要原文） |
|:--|:--|
| **正负经验双记忆** | 策略模板（成功轨迹）+ 错误模式（失败形态）——检索时两者共同组成提示 |
| **跨任务可泛化优化** | 记忆累积使优化随任务演进，而非每任务从零搜索 |
| **成本降低** | 一致优于基线且显著降低优化成本 |

**限制（摘要/分析明示）**：① 基准未具名、具体增益未在摘要级可见（未验证）；② memory editing（LLM 编辑记忆）的编辑质量控制机制未在摘要讨论；③ 场景为提示词优化——与 Kairos 核心域（记忆系统本体）距离较远，价值主要在机制类比。

## 可吸收增量（具体到机制/参数/设计）

1. **错误模式库（重点吸收候选）**：差异检验（§5.5）/升华管道（§5.2）扩展评估——把差异检验失败记录组织为**结构化错误模式**（失败形态 + 出现情境 + 已尝试修正），作为负向经验的一等记忆形态；检索时与正向经验共同使用（提示词优化器 §10.16 与执行路径均可引用）；错误模式库的写入须过质检（避免错误模式自身被污染）。
2. **提示词优化器记忆化参考（评估注记）**：§10.16 补充注记——外部 MemAPO 形态（成功轨迹→策略模板 + 错误生成→错误模式 + 组合检索）作为 Kairos 提示词优化器落地参考样本；与 PAPER-11 AEL 失败诊断合并评估。
3. **memory editing 门禁声明（张力注记）**：AT-02 更新——MemAPO 的 memory editing（LLM 编辑记忆）与 Kairos 差异检验门禁取向张力记录；编辑产物须过差异检验与质检三查。

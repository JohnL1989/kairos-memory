## 核心机制（问题/方法/实验）

**问题**：长程语言智能体在有限运行时记忆预算下运行，但既有记忆机制按**描述性标准**（相关性、显著性、摘要质量）组织经验。论文主张：对智能体而言，记忆的价值**不在于忠实描述过去，而在于在固定预算下保留必须相互分离的历史区分（distinctions between histories）以支撑良好决策**。

**方法（决策导向率失真形式化 + 在线学习器）**：
1. **率失真建模**：把记忆质量度量定义为**压缩导致的决策质量损失**——记忆是压缩，其失真 = 决策质量的退化。
2. **精确遗忘边界（exact forgetting boundary）**：形式化推导「什么可以安全遗忘」的精确边界。
3. **记忆-失真前沿（memory-distortion frontier）**：刻画记忆预算与决策质量之间的最优权衡曲线。
4. **DeMem 在线学习器**：只在数据**证明共享状态会引发决策冲突**时细化记忆分区（refine partition），并提供 **near-minimax regret** 理论保证。

**实验**：受控合成诊断 + 长程对话基准——**相同运行时预算下**一致增益，支撑「记忆应保留对决策重要的区分，而非描述」。

## 关键发现与数据

| 发现 | 数据（摘要原文） |
|:--|:--|
| **记忆价值 = 决策效用** | 记忆不因忠实描述而值，而因保留「必须区分的决策关键历史」而值 |
| **遗忘边界可精确推导** | 率失真形式化给出「可安全遗忘」的精确边界 + 记忆-失真最优权衡前沿 |
| **冲突驱动更新** | 仅在数据证明共享状态引发决策冲突时细化分区（在线学习，near-minimax regret 保证） |
| **同预算增益** | 相同运行时预算下合成诊断与长程对话基准一致增益 |

**限制（摘要/分析明示）**：① 实验具体数字未在摘要级可见（未验证）；② 「决策质量」的度量定义（如何测决策质量损失）未详述；③ 理论保证（near-minimax regret）的适用假设（决策模型形式）未在摘要级可见。

**重点回答**：与 Kairos 直接对话的是**价值独立性公理（蓝图 §5.3）与遗忘调度器（§5）**。论文价值：① 遗忘决策的形式化工具（率失真遗忘边界、代价函数）可吸收为遗忘调度器理论参考；② 「记忆价值=决策效用」与 Kairos 认知真实性立场形成根本张力——记录为「决策效用 vs 认知真实性」双标准问题，不吸收为裁决依据；③ 冲突驱动更新与差异检验互证。

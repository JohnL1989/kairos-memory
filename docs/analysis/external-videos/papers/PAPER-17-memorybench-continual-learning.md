## 核心机制（问题/方法/实验）

**问题**：既有 LLM 记忆基准多聚焦「同质阅读理解任务 + 长输入」，而非检验系统在**服务期从累积的用户反馈中持续学习**的能力。数据/参数/测试时计算扩张的边际收益已近上限，记忆与持续学习成为新方向，但缺少相应评估。

**方法（用户反馈模拟框架 + 多域基准）**：
1. **Task Provider（任务提供器）**——把案例格式化为 (q, v, c)，跨域、跨任务格式采样。
2. **User Simulator（用户模拟器）**——「LLM-as-user」范式（基于 Mistral-Small-3.2-24B-Instruct）+ 可编程动作映射，生成人类难以区分的反馈；系统回答后模拟器发出**显式冗长反馈**（满意度评分 0–9）+ **隐式动作反馈**（like 等）+ 终止信号。
3. **Performance Monitor（性能监视器）**——用原生指标 + LLM-as-judge 评估测试查询。

把历史案例批次+反馈日志回灌系统，测量**留出测试性能是否随反馈提升**。支持记忆分类学：**声明性 vs 程序性**、语义/情景类型。

**域与规模**：三域（开放域 / 学术与知识 / 法律），英中双语，约 20,000 案例（11 个上游数据集：LoCoMo、DialSim、LexEval、JuDGE、IdeaBench 等）。
**任务格式**：按输入×输出长度（600 token 边界）四格式——LiSo/LiLo/SiLo/SiSo（QA、对话、长文写作、判断任务）。
**实验协议**：四协议——off-policy（批量重放，主要结果）/ stepwise off-policy（分批重放）/ on-policy（实时生成，真实持续学习环）/ training performance（过拟合与灾难遗忘检测）。
**基线**：8 系统——Vanilla、BM25-M/S、Emb-M/S、A-Mem、Mem0、MemoryOS。

## 关键发现与数据

| 发现 | 数据（第三方交叉核验，未验证原文） |
|:--|:--|
| **核心警示：高级记忆框架不敌简单检索** | Mem0/MemoryOS/A-Mem 一般**无法一致超越** BM25 或嵌入检索基线——「有效性与效率都远不令人满意」 |
| **程序性知识缺口** | 系统能存事实（声明性），但难以用反馈中的程序性知识改善实际表现 |
| **用户反馈模拟可生成难辨真伪反馈** | LLM-as-user（Mistral-Small-3.2-24B）+ 可编程动作映射 |
| **评估协议完备** | 四协议覆盖批量/流式/在线/过拟合检测四个持续学习评估面 |

**限制（摘要/分析明示）**：① 具体数字未在摘要级可见（未验证）；② 用户模拟器以 LLM 模拟「用户」——模拟与真实用户反馈的差距未在摘要讨论；③ 结论对「记忆系统价值」的整体质疑——需区分「工程实现质量」与「记忆范式本身」两回事（未验证）。

**重点回答**：与 Kairos 直接对话的是**基准设计（benchmark-plan §3.11/§3.13）与记忆价值实证立场（§1.7）**。论文价值：① 最重要的外部警示——Mem0/MemoryOS/A-Mem 等高级记忆框架无法一致超越简单 BM25/嵌入检索，「复杂记忆 ≠ 更优」须作为基准设计红线（简单基线对照）；② 用户反馈模拟 + 四协议为持续学习评估提供完整方法论；③ 程序性知识难以学习的实证为升华管道/行为层研究议程提供动因。

## 可吸收增量（具体到机制/参数/设计）

1. **简单基线对照门禁（基准红线强化）**：benchmark-plan §3.11 基准设计红线补充——任何记忆系统评估必须含「简单基线对照」（BM25/嵌入检索/无记忆），验证记忆机制的增量价值；MemoryBench「高级框架不敌简单 RAG」为红线制定依据（第三方口径标注）。
2. **用户反馈模拟评估维度（方法论注记）**：benchmark-plan §3.13 补充——「服务期用户反馈累积 → 留出性能提升」评估维度（显式评分 0–9 + 隐式动作 + 终止信号），声明性/程序性记忆分型度量；四协议（批量/流式/在线/训练重测）为持续学习评估参考。
3. **程序性知识学习研究动因（证据注记）**：D-427 记忆饱和研究议程补充——外部实证「系统存事实易、从反馈改行为难」为升华管道行为层研究提供动因（第三方口径）。
4. **基准域规模参考（注记）**：benchmark-plan 测试数据规模节记录——三域（开放/学术/法律）双语 2 万案例为域设计参考（Kairos 个人记忆域取向不变）。

## 存疑与未验证

- **未读全文**：具体性能数字（各基线差距）未验证；ICML 2025 收录为第三方口径
- 用户模拟器与真实用户反馈的差距（模拟失真）未在摘要讨论
- 「高级框架不敌简单检索」结论对具体框架（Mem0/MemoryOS 版本）的适用范围未核验
- 声明性/程序性分型的度量实现细节未核验
- v7（2026-06-03）相对 v1 的改动未核验

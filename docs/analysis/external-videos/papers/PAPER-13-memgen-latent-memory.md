## 核心机制（问题/方法/实验）

**问题**：Agent 记忆两条既有路线各有缺陷——**参数化记忆**（SFT/DPO/GRPO 微调，把经验内化进权重）有灾难性遗忘风险；**检索式记忆**（外部数据库，retrieve-inject 一次性注入）是静态、单次的「取回-注入」流程，捕捉不到记忆与推理之间流动的实时交互。论文提出**第三条路**：生成式隐式记忆（generative latent memory），让记忆与推理在推理过程中紧密交织。

**方法（两模块，主模型零微调）**：
1. **Memory Trigger（记忆触发器）**——LoRA 适配器实现的**元认知决策单元**：自回归解码过程中持续监视推理状态（hidden state 序列），决定每个时刻是否唤起记忆；采用**句子级激活策略**（只在句号/逗号等标点处判定），平衡效率与连贯性；以 RL 训练，目标同时最大化任务回报与鼓励稀疏高效取回。
2. **Memory Weaver（记忆织入器）**——以当前状态为刺激，构造**隐式 token 序列（latent token sequence）**作为机器原生记忆，注入推理流丰富进行中的认知。

主模型不被微调——外部知识只注入两个外部记忆模块，解码期动态注入。

**实验**：8~9 个基准 × 5 个域（web 搜索、具身动作、数学推理、科学推理、代码生成）；Qwen2.5-1.5B-Instruct 与 SmolLM3-3B 骨干。

## 关键发现与数据

| 发现 | 数据（第三方交叉核验，未验证原文） |
|:--|:--|
| **vs 外部检索式记忆** | 超越 ExpeL/AWM 最高 **+38.22%**（8 基准） |
| **vs 参数化微调** | 超越全参微调 GRPO 最高 **+13.44%**，且**不微调主模型** |
| **具身动作任务** | ALFWorld（SmolLM3-3B）：18.96% → 63.60%（**+44.64%**） |
| **代码生成** | KodCode（Qwen3-8B）：**+27.06%** |
| **跨域泛化** | 触发器的调用策略有域感知：训练域（GSM8K）调用最频、相近域（GPQA）适中、异域（KodCode）最少——防负迁移 |
| **持续学习抗遗忘** | 四数据集顺序训练后，AQuA 知识保留 **40.34%** vs SFT 28.61%（显著优于 SFT 灾难性遗忘） |
| **自发涌现记忆分工** | 无显式监督下，t-SNE/功能消融揭示三个自发组织的功能簇：**规划记忆**（消融→规划失败增多）、**程序性记忆**（消融→工具/格式错误增多）、**工作记忆**（消融→任务误解与推理不一致） |

**限制（摘要/解读明示）**：① 隐式记忆**不可读、不可审计**——记忆内容以 latent token 形态存在，无人类可读副本；② 记忆触发器在推理期持续监视 hidden state，推理开销增量未完整量化；③ 主模型为 1.5B~8B 小骨干，大模型行为未验证；④ 「自发涌现分工」为分析性发现（t-SNE/消融），机制解释未完全证实。

**重点回答**：与 Kairos 直接对话的是**可审计性红线（§1.7/§5.5）与记忆形态定位（§0.3）**。论文价值：① latent 记忆形态不可审计——与 Kairos 见证锚定立场**冲突**，存储形态不采纳；② 但「元认知触发+推理交织+功能分工自发涌现」三机制独立实证 Kairos 预测器/推理皮层/分层设计的合理性；③ 与 PAPER-20 Mem-W 同属 latent-native 路线（本批次双篇互证），Kairos 须保持符号化可审计立场并记录张力。

## 可吸收增量（具体到机制/参数/设计）

1. **元认知触发机制候选（评估注记）**：预测器（§3.2）/注意力调度器（§9）补充注记——「持续监视推理状态、句子级标点处判定是否需要记忆」作为触发调度的候选设计；RL 训练触发策略的路径与 §10.14 RL 权重优化器对照。**须过门禁**：触发决策可审计（何时触发、为何触发须可解释），不吸收 latent 形态本身。
2. **「不可审计记忆形态」矛盾记录（红线注记）**：在架构 §1.7 监督平面或安全红线（§8）注记中记录——MemGen 式 latent 记忆（隐式 token，无人类可读副本）与可审计性红线冲突，作为「记忆承载形态必须可审计」的反面样本；与 PAPER-20 Mem-W 同族。
3. **功能分工涌现证据（注记）**：在 §5 存储层分工注记中记录——无监督下规划/程序性/工作记忆功能簇自发分化（第三方口径），作为 Kairos 分层设计合理性的外部实证数据点；标注第三方口径未验证。
4. **持续学习对比证据（注记）**：为 D-427 记忆饱和与持续学习研究议程补充——外部记忆形态相对 SFT 的抗遗忘数据点（40.34% vs 28.61%，第三方口径），基准立项时纳入对照。
